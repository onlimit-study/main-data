This repository contains the source files for creating the data package
for the main phase of the [ON LiMiT](https://onlimit.org/) study. The
data package includes both the metadata and the data. The metadata is
publicly accessible from this repository while the data is stored on the
[GenomeDK](https://genome.au.dk) server at [Aarhus
University](https://au.dk), Denmark.

Check out our [website](https://onlimit-study.github.io/main-data) for
more information, such as the
[metadata](https://onlimit-study.github.io/main-data/docs/) on the data
package and its contents.

>
> This data package was generated from the [Template Data
> Package](https://github.com/seedcase-project/template-data-package)
